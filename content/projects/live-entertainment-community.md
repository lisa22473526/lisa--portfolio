# 娛樂直播與賽事互動平台 App

## 一句話亮點

結合「體育賽事直播」、「即時數據資訊」與「主播社群互動」的一站式平台，解決使用者看球賽時需要跨 App 切換資訊與討論的痛點。

## 核心問題

舊版或傳統體育 App 的畫面切割混亂，使用者在「看直播」、「瀏覽比分與數據」及「社群聊天討論」之間切換的成本很高。

直播聊天室訊息快速洗版，也容易讓重要賽事資訊被淹沒，使觀賽與互動彼此干擾。

### 使用者痛點

1. 觀看直播時需要離開當前畫面查詢比分或數據。
2. 直播、資訊與聊天室缺乏清楚且連續的操作架構。
3. 聊天訊息密度過高，影響重要資訊的辨識。
4. 橫屏與豎屏具有不同需求，單一版面無法兼顧兩種情境。

## 解決方案與總體架構

重新規劃 Information Architecture，打造可依觀賽情境彈性切換的「直播／資訊／聊天」三合一介面。

| 體驗 | 目的 |
| --- | --- |
| 直播 | 提供不中斷且具沉浸感的觀賽體驗 |
| 即時資訊 | 不離開直播即可掌握比分與賽事數據 |
| 社群互動 | 提供主播互動、聊天室、跟單及應援行為 |

## 關鍵設計決策

### 決策 A：聊天室的重要訊息與高密度互動

> 待補：聊天室的具體設計方案、選擇此方案的原因，以及 Before / After 畫面。

建議回答：如何避免重要賽事訊息被快速聊天內容淹沒？哪些訊息需要提高層級、固定顯示或另外分類？

### 決策 B：橫豎屏情境下的聊天室與數據佈局

全螢幕橫屏觀賽時，聊天室以半透明彈幕浮層呈現。使用者五秒未操作後，自動隱藏互動 UI，減少畫面干擾並增加沉浸感；再次操作即可喚醒介面。

豎屏則提供完整的資訊頁籤與聊天頁籤，使使用者能在較適合操作與閱讀的版面中查詢資料及參與互動。

- 橫屏優先：直播內容與觀看沉浸感。
- 豎屏優先：完整資訊、閱讀效率與深度互動。

## 功能成果一：多張推單 UI

上線日期：2025/12/25

透過提高推單按鈕的辨識度並加入即時推單彈窗，改善使用者發現與執行跟單的流程。

### 成效

- 跟單勝率由 **36.67%** 提升至 **46.15%**，增加 **9.48 個百分點**。
- 跟單總額 Turnover 成長 **70.4%**。
- 參與互動成員數 Follow User 成長 **47.5%**。

### 產品價值

- 提升使用者對跟單功能的信心與參與意願。
- 增加 App 內互動與停留動機。
- 將介面可見性改善轉化為商業成果。

> 待確認：來源文件寫作「增加 9.48%」。36.67% 到 46.15% 的差異是 9.48 個百分點；若要呈現相對成長率，需另行確認統計口徑。

## 功能成果二：沉浸式觀賽 UI

以 UI 自動淡出與互動喚醒機制降低觀看干擾，並改善橫屏滿版體驗。

### 成效

- 人均觀看時長提升 **21%**。
- 整體人均流水 Member TO 成長 **60.2%**。
- 乾淨流成長 **535.7%**。
- 聊天率下降 **55.5%**。

### 設計權衡

聊天率下降是介面簡化後需要正視的結果，但同時換得觀看時長及核心商業指標的大幅成長。案例內頁應完整呈現這項取捨，而不是只展示正向數據。

這項結果反映產品當時選擇以「觀看沉浸感」作為橫屏體驗的主要目標；後續仍可探索不干擾直播內容、但能維持互動意願的設計方式。

## 功能成果三：活動體驗優化

### 商業與使用者價值

- 聊天室訊息量成長 **14.67%**，由 128k 增加至 147k 則。
- 人均送禮頻率成長 **14.12%**，由 5.03 次增加至 5.74 次。
- 平均觀看時長成長 **5.11%**，由 36.99 分鐘增加至 38.88 分鐘。

### 問題一：難度斷層造成初期流失

進入 Phase 2 的玩家中，有 **67.5%（537 筆）**停留在 1–10% 進度，進度中位數為 10%。數據顯示使用者體驗約十分鐘後，可能因目標距離過遠或門檻過高而放棄。

#### 優化策略

將活動門檻調整為「累計投注每滿 RM20，進度增加 5%」，以階梯式回饋降低單次決策壓力，並嘗試活化停留在 10% 區間的 500 位以上潛在使用者。

### 問題二：活動獎勵與打賞禮物混淆

活動達成後的獎勵與打賞主播的禮物使用相似 UI 樣式，導致部分使用者誤以為只需要完成打賞即可獲得活動獎勵。

#### 使用者回饋

使用者會將活動獎勵與主播打賞禮物混淆。

#### 優化策略

> 待補：補充兩類物件的視覺區隔、文字說明、流程提示或狀態回饋方案。

## 回顧與學習

這個專案顯示，降低介面干擾可以明顯改善觀看及商業表現，但產品體驗的優化不一定會讓所有指標同時上升。設計決策需要先明確定義主要目標，再將正向成果與負向影響一起呈現及評估。
